# Lobster Tycoon

An idle harbor tycoon browser game. Tap the lobster to haul cash, build from one trap to a deep-sea fleet, and sell the business for reputation stars that speed up your next run.

Play: https://jatreat.github.io/lobster-tycoon/

Everything is in one self-contained `index.html` (fonts embedded). It integrates the CrazyGames HTML5 SDK v3 for ads and cloud saves, and falls back to local saves elsewhere. Store covers are in `covers/`.
